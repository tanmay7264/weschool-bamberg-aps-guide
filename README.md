# WeSchool to Bamberg APS Exchange Guide

Interactive student SOP for short-term institutional exchange, with a clickable responsibility flowchart, document checklist, form guidance and official source links.

Public sources were verified on 24 November 2026. Cohort eligibility, PGDM classification and group payment instructions require institutional confirmation as explained in the guide.

The site consists of a self-contained index.html and is published from the root of the main branch using GitHub Pages. Checklist ticks stay in the visitor's browser. Cohort worksheet text is not saved or transmitted.

Update index.html and push to main to publish a revision. Recheck APS and university instructions before each new cohort.
